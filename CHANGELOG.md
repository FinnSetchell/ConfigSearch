# Config Search

## [1.1.0] - 2026-09-26

### Added
- Support for Minecraft 26.3

### Changed
- On 26.3 the search button now sits next to the mod list's search box

## [1.0.0] - 2026-07-23

First release.

- Search every installed mod's config options from a bar on the mods list.
- Click a result to open the setting directly.
- Detects options from the major config libraries.
- Any mod can register its own entries via the `configsearch` service.
