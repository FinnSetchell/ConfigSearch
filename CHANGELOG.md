# Config Search

## [1.1.0] - 2026-09-26

### Added
- Support for Minecraft 26.3
- Works with Catalogue: the search button now shows in Catalogue's mod list
- Configs that only show up in Catalogue can now be searched

### Changed
- Mod Menu is no longer required, you can use Catalogue instead

## [1.0.0] - 2026-07-23

First release.

- Search every installed mod's config options from a bar in Mod Menu.
- Click a result to open the setting directly.
- Detects options from the major config libraries.
- Any mod can register its own entries via the `configsearch` entrypoint.
